# Телефонная книга

Веб-приложение для управления контактами. Позволяет просматривать список контактов, добавлять новые записи, редактировать существующие и удалять их через веб-интерфейс.

## Возможности

- Просмотр списка контактов
- Добавление новых контактов
- Редактирование контактной информации
- Удаление контактов
- Хранение данных в базе данных
- REST API для управления контактами

## Технологии

- **Python** — логика приложения
- **FastAPI** — серверная часть и REST API
- **SQLAlchemy** — взаимодействие с базой данных
- **PostgreSQL** — хранение данных
- **HTML, CSS, JavaScript** — пользовательский интерфейс

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone <ссылка-на-репозиторий>
   cd <папка-проекта>
   ```

2. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Активируйте виртуальное окружение.

   **Windows:**

   ```bash
   .venv\\Scripts\\activate
   ```

   **Linux / macOS:**

   ```bash
   source .venv/bin/activate
   ```

4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Запуск

Запустите приложение командой:

```bash
uvicorn main:app --reload
```

Откройте в браузере адрес:

`http://127.0.0.1:8000`

Интерактивная документация API доступна по адресу:

`http://127.0.0.1:8000/docs`

## API

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/contacts` | Получить список контактов |
| GET | `/contacts/{id}` | Получить контакт по ID |
| POST | `/contacts` | Создать контакт |
| PUT | `/contacts/{id}` | Обновить контакт |
| DELETE | `/contacts/{id}` | Удалить контакт |
